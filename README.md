One weather forecast (128 characters) for Mumbleton, a city that does not exist, written by a deterministic program (`main.ts`, Node stdlib only, no network):

> Mumbleton: overcast, with a 90% chance your umbrella turns inside out before you reach the platform. The 8:04 is late, as usual.

`main.ts` validates the entry (1–140 chars, single line, no trailing newline), writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`, and verifies the file on disk is byte-identical (sha256 logged).
